# INVENTA.AI — Roadmap + Go-to-Market LATAM

## Roadmap (12 meses)
- **M0–M2 · Demo que vende**: esta repo (web + api + ai-engine + WhatsApp approvals). 10 pilotos pagados en Lima (Gamarra, ferreterías, distribuidoras). Meta: S/ 5,000 de ahorro/30d por piloto o no pagan.
- **M3–M5 · Integraciones que escalan**: Shopify, Mercado Libre, Excel/Sheets 1-clic; scoring crediticio v1 con 2 bancos + 1 fintech. Fill-rate +5pts demostrable.
- **M6–M9 · Expansión**: WooCommerce, Falabella, POS (Alegra/Nubox); forecast v2 (LightGBM por categoría); app móvil GA; entrada CDMX + Bogotá.
- **M10–M12 · Foso**: red de proveedores (Alicorp/Backus/Gloria: OC automática), financiamiento embebido con revenue-share, multi-moneda y multi-país. Serie A.

## GTM LATAM (por qué gana)
1. **Wedge Perú**: 2.5M pymes, quiebre crónico, WhatsApp como OS. Venta B2B consultiva + garantía ROI elimina objeción precio.
2. **Canales**: WhatsApp (alertas/aprobaciones) como loop viral; partnerships con proveedores grandes (ellos empujan la adopción); integradores POS/ERP locales como afiliados.
3. **Pricing**: SaaS $500–$5,000/mes + % del ahorro + fee de financiamiento. El cliente paga con lo que recupera, no con su flujo.
4. **Métricas Serie A**: NRR > 120% (más SKUs + financiamiento), CAC payback < 6m, 40% de OCs aprobadas por WhatsApp, fill-rate +8pts en 90d.
5. **Defensibilidad**: historial por SKU/tenant (data network effect) + scoring crediticio propietario + red de proveedores. Cada cliente hace más inteligente al siguiente sin filtrar datos (federated features).
